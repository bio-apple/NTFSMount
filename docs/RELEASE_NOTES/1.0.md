# NTFSMount 1.0

Personal-use. Not notarized. Do not mirror or treat as a product until FUSE-T written permission and Apple notarization. See NOTICE.

Apple Silicon and macOS 13.0+ only. GitHub Latest points at this package (`/releases/latest/download/NTFSMount.pkg`). Writing or formatting an NTFS disk can cause data loss; back up first. FUSE-T `go-nfsv4` is not GPL.

`CFBundleShortVersionString` is 1.0.

## What's new

- Installer package places NTFSMount.app in `/Applications`.
- The package installs the mount helper before the installer finishes.

## Fixes

- None in this notes file. This is the current tree, not a comparison with an older tag.

## Breaking Changes

- None. This is the only published release.

## Changes

- In-app updates open the package download. Sparkle stays off until a notarized build.

## Known issues

- Unnotarized: Gatekeeper can block first launch (Control-click → Open, or System Settings → Privacy & Security → Open Anyway).
- Personal-use only (bundled FUSE-T). Do not mirror.

## Helper: reinstall required?

- **No** for a first install: the package installs the helper.
- Reinstalling the package installs the helper again.

## Old config compatibility

- **UserDefaults:** current keys apply to this build.
- **Auto-mount:** external NTFS can mount writable by default after you agree. Turn it off in Settings.
- **Helper stamp:** the package writes `helper.stamp` and `allowed.cdhash`.
- **Leftover sudoers:** `/etc/sudoers.d/ntfs-rw` is deleted on install and uninstall. Do not keep NOPASSWD leftovers.
