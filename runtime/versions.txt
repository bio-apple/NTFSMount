# 复现
#   仓库 runtime/ 已含 ntfs-3g / mkntfs / ntfsfix / libntfs-3g.90.dylib 时，
#   ./scripts/prepare-runtime.sh 跳过 brew（本机与 CI 皆然；不需要 Homebrew）。
#   打包机若需刷新这些文件：仅当该 macOS 有 bottle 时才
#     brew install --force-bottle ntfs-3g
#   禁止 brew install --build-from-source ntfs-3g，禁止 brew install macfuse / fuse-t。
#   ./scripts/prepare-runtime.sh  # 拉 FUSE-T 1.2.7 pkg 并校验 SHA256
#                                 # 不必启动 FUSE-T.app；不会静默把 FUSE-T 装进系统
#
# 换 FUSE-T 大版本时：改 scripts/prepare-runtime.sh 里的 FUSE_T_VERSION，
